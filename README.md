# DInfinity Loader 1.0
#**IMPORTANT THIS WILL CONTAIN SKYLANDERS EVENTUALLY**
**by Bobzilla07**

DInfinity Loader is an Xbox 360 plugin for **Disney Infinity 1.0, 2.0, and 3.0**.

It gives the games a virtual Infinity Base and lets you load characters, Play Sets, and Power Discs without a physical base or figures.

## Features

- Works with Disney Infinity **1.0, 2.0, and 3.0**
- Virtual Infinity Base
- Load and remove characters
- Load and remove Play Sets / Games
- Circular Power Discs
- Hexagonal Power Discs
- Customizable menu colors
- Custom menu keybind
- One shared `DInfinityLoader.ini`
- Settings are saved automatically

## Using It

Load `DInfinityLoader.xex` with your normal Xbox 360 plugin or module loader, then start one of the supported Disney Infinity games.

When the virtual Base connects, DInfinity Loader will show a notification with your saved menu keybind.

The default keybind is:

`LT + D-Pad Left`

You can change it from **Settings**. The keybind can be one button or any combination of controller buttons and triggers.

## Settings

Settings are saved in:

`DInfinityLoader.ini`

Keep the INI in the **same folder as `DInfinityLoader.xex`**.

The same INI stores the menu colors, panel opacity, and menu keybind.

## Title Updates

This release is made for the latest Title Updates used during development.

If you see:

`Title Update Mismatch - use the latest TU`

make sure the game is running the correct/latest Title Update before trying again.
